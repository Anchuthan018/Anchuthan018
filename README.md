### 🧠 Featured Projects

#### 🖼️ [Smart Studio — AI Event Photo Management Platform](https://github.com/Anchuthan018)
Face-recognition-based instant photo sharing for event guests, with an XGBoost classifier for social-context photo grouping and a custom dual-branch blur detector. Deployed as containerized microservices on Azure Container Apps.
`React.js` `PyTorch` `Flask` `InsightFace` `YOLOv10` `XGBoost` `Docker`

#### 📊 [Stock Master — AI Inventory & Sales Forecasting](https://github.com/Anchuthan018)
XGBoost regression model with 29 engineered features (lag variables, rolling stats, seasonal encodings) predicting monthly product demand, served via a Flask REST API with a React + Recharts dashboard.
`XGBoost` `scikit-learn` `Pandas` `Flask` `React.js`

#### 🚨 [DRMS — Disaster Resource Management System](https://github.com/Anchuthan018)
Microservices platform for disaster shelter operations — batch inventory tracking, shelter-to-shelter transfers, donation traceability, and a real-time transparency timeline behind a JWT-secured Spring Cloud API Gateway.
`Java` `Spring Boot` `Spring Cloud` `React.js` `MySQL` `RabbitMQ`

#### 🏠 [HomeMate — Home Services Mobile App](https://github.com/Anchuthan018)
Multi-app platform (User, Provider, Admin) for real-time location-based service matching, built with Flutter and Firebase, integrated with Google Maps API.
`Flutter` `Firebase` `Google Maps API`
